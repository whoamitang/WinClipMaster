# Initial Public Release

WinClipMaster v1.0.0 is the first release of a lightweight Windows clipboard history utility.

- Saves copied text locally in an SQLite database.
- Runs as a standalone Windows executable; no Python installation is required.
- Stores history at `%LOCALAPPDATA%\WinClipMaster\history.db`.

Download `WinClipMaster.exe` below, run it, and keep the console window open to record clipboard text. Press Ctrl+C or close the window to stop. Clipboard history is stored as plain text.
